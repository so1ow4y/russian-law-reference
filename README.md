# Russian Law Reference

Одностраничный правовой справочник РФ по IT, информационной безопасности, искусственному интеллекту и рекламе.

Работает в браузере на компьютере и телефоне. Не требует установки, регистрации или сервера приложений.

## Открыть справочник

Справочник доступен онлайн на **GitHub Pages**:

**[Открыть Russian Law Reference](https://so1ow4y.github.io/russian-law-reference/)**

## Возможности

- Поиск по загруженным статьям и пунктам.
- Две независимые классификации: тип документа и тематика.
- Тематические фильтры: **Все / IT · ИБ · AI / Реклама**.
- Навигация по частям, разделам, главам и статьям.
- Просмотр отдельных статей и всех загруженных норм документа.
- Заметки к документам и статьям.
- Цветные выделения с комментариями.
- Поиск по заметкам, выделениям и цветам.
- Экспорт и импорт заметок в JSON.

Документы хранятся без тематических копий: одна статья может относиться к нескольким темам.

## Состав справочника

В текущей версии — **24 документа**, включая:

- Гражданский кодекс РФ — часть IV;
- тематическую подборку статей УК РФ;
- федеральные законы об информации, персональных данных, связи, электронной подписи, рекламе и защите конкуренции;
- Закон РФ «О защите прав потребителей»;
- постановления, распоряжения и приказы по вопросам рекламы.

Корпус содержит 888 отдельных статей и 104 пункта, служебных блока и объединённых диапазона статей.

КоАП РФ и части I–III ГК РФ в текущую версию не включены.

## Как пользоваться

1. Выберите тематику: **Все**, **IT / ИБ / AI** или **Реклама**.
2. В разделе «Документы» выберите тип документа, документ и статью. При наличии структуры можно уточнить часть или главу.
3. Откройте выбранную статью или весь документ в пределах выбранной темы.
4. Для поиска перейдите в «Справочник».
5. Чтобы добавить заметку, нажмите **✎**. Для выделения выберите фрагмент текста и цвет.
6. Все сохранённые пометки доступны в разделе «Пометки».

Фильтр **«Все»** показывает весь загруженный текст. Узкие темы показывают только нормы с соответствующими тематическими метками.

## Заметки и резервные копии

Заметки, выделения и комментарии автоматически сохраняются в `localStorage` текущего браузера.

- Они не отправляются на сервер и не записываются в GitHub-репозиторий.
- Между устройствами и браузерами автоматической синхронизации нет.
- Очистка данных сайта может удалить локальные заметки.
- Для резервной копии откройте **«Заметки» → «Экспортировать все заметки»** и сохраните JSON.
- Для восстановления выберите JSON в разделе импорта. Доступны объединение с текущими пометками и полная замена.

При переходе с локального HTML на опубликованный сайт сначала экспортируйте заметки из локальной версии, затем импортируйте их на сайте.

## Запуск

### Локально

Откройте `index.html` в браузере. Тексты документов, стили и логика приложения встроены в HTML.

### GitHub Pages

1. Разместите `index.html` и пустой файл `.nojekyll` в корне репозитория.
2. Откройте **Settings → Pages**.
3. Выберите **Deploy from a branch**.
4. Укажите ветку **main** и папку **/ (root)**.
5. Сохраните настройки и дождитесь публикации.

README описывает проект; стартовой страницей приложения служит `index.html`.

## Источники и обновления

Тексты перенесены из предоставленных PDF КонсультантПлюс. Сведения об источнике и редакции отображаются в карточке документа.

PDF не требуются для чтения встроенных текстов. Для работы ссылок «Открыть исходный PDF» соответствующие файлы должны быть опубликованы по указанным в приложении путям.

Обновления законодательства автоматически не загружаются. Полнота корпуса ограничена загруженными источниками. Тематические метки служат для навигации и не изменяют текст документов.

Справочник предназначен для поиска и изучения норм. Перед практическим применением проверяйте действующую редакцию и дату вступления положений в силу.
